## 残課題・制約

- 本番用 JavaScript は約1.2 MB、gzip 約330 KB。地図ライブラリによるチャンクサイズ警告が残る（ビルド失敗ではない）。
- 数時間〜数日の連続表示によるメモリ使用量・更新の安定性は未検証。
- Safari / Firefox と実機スマートフォンは未検証。狭い画面はデスクトップ Chrome の画面サイズ変更で確認。
- オフラインで未取得の地域・倍率へ移動した場合、その範囲のタイルを復元できない。
- 配信期間終了、CORS、URL、外部データ形式の変更が発生した場合はアダプターの修正が必要になる可能性がある。
- 永続キャッシュ、長期履歴、デプロイは今回の実装範囲外。
