# DESIGN.md

画面の見た目と操作は、Apple Human Interface Guidelines（HIG）に沿わせる。この文書は、HIGをこのWebアプリへどう当てはめるかと、HIGから意図して外している点をまとめる。

設計値の実体は `src/app/tokens.css`、部品のスタイルは `src/app/styles.css` にある。部品は設計値だけを参照し、色や大きさを直接書かない。

## 1. 原則

HIGの3つの原則を、このアプリでは次のように解釈する。

| HIGの原則 | このアプリでの意味 |
| --- | --- |
| Deference（コンテンツを主役にする） | 主役は地図と気象データ。操作パネルやカードは地図の上に浮かぶ層として置き、地図を過度に隠さない。 |
| Clarity（明瞭さ） | データ時刻と更新状態は常に読める。文字の大きさはテキストスタイルにそろえ、階層を色の濃さ（主・副・補助）で表す。 |
| Depth（奥行き） | 浮かぶ層は半透明の素材と影で地図から切り離す。どの層が上にあるかが一目で分かるようにする。 |

## 2. Webで使えないもの

- **SF Pro（フォント）と SF Symbols（アイコン）**：ライセンス上、Apple製品向けのアプリでしか使えず、Webには埋め込めない。
  - フォントはシステムフォントを指定する。Apple端末では SF Pro とヒラギノ、Windowsでは Segoe UI と游ゴシック UI で表示される。
  - アイコンは SF Symbols に似た線の太さと角の丸みで自作のSVGを描く。アイコン用の依存パッケージは追加しない。

## 3. 設計値

### 色

ライト/ダークはOSの設定（`prefers-color-scheme`）に従う。名前はHIGの動的システムカラーに対応させる。

| 設計値 | ライト | ダーク | 用途（HIGの対応） |
| --- | --- | --- | --- |
| `--color-label` | `#1d1d1f` | `#f5f5f7` | 本文（label） |
| `--color-label-secondary` | `#636366` | `#a1a1a6` | 補足、時刻の説明（secondaryLabel） |
| `--color-label-tertiary` | `#8e8e93` | `#6e6e73` | 開閉の印など、読めなくても支障のないもの（tertiaryLabel） |
| `--color-tint` | `#0058c4` | `#64b0ff` | リンク、枠なしボタンの文字（tint / systemBlue） |
| `--color-tint-fill` | `#0071e3` | `#0071e3` | 塗りつぶしボタン、選択中の項目、チェックボックス |
| `--color-on-tint` | `#fff` | `#fff` | 塗りつぶしボタンの文字 |
| `--color-separator` | `rgba(60,60,67,.29)` | `rgba(84,84,88,.65)` | 区切り線（separator） |
| `--color-fill` ほか3段階 | HIGの値 | HIGの値 | ボタンや入力欄の下地（systemFill〜tertiarySystemFill） |
| `--color-bg` | `#f2f2f7` | `#000` | ページの下地（systemGroupedBackground） |
| `--color-bg-elevated` | `#fff` | `#1c1c1e` | 不透明なパネル（secondarySystemGroupedBackground） |
| `--color-green` | `#248a3d` | `#30d158` | 正常を示す点（systemGreen） |
| `--color-orange` | `#b83000` | `#ff9f0a` | 古いデータ、取得失敗（systemOrange） |
| `--color-purple` | `#8944ab` | `#da8fff` | 降水予測の表示（systemPurple） |

警報の色（警戒レベルの色）、アメダスの色の尺度、雨雲の色は気象データの表現なので、ここには含めない。ライト/ダークで変えない。

### 文字

HIGのテキストスタイル（iOS / iPadOS の標準サイズ）を使う。日本語の複数行が詰まって見えないよう、行の高さはHIGより広げる。

| 設計値 | 大きさ / 行の高さ | 主な用途 |
| --- | --- | --- |
| `--text-title2` | 22 / 30px（太字） | アプリ名 |
| `--text-headline` | 17 / 24px（太字） | セクション見出し、カードの見出し、主要ボタン |
| `--text-body` | 17 / 24px | 表示の切替、観測値、警報の種別 |
| `--text-subheadline` | 15 / 21px | ボタン、状態、見出し横の時刻、警告文 |
| `--text-footnote` | 13 / 19px | 説明文、補足 |
| `--text-caption1` | 12 / 17px | 目盛り、時間軸の両端、出典 |
| `--text-caption2` | 11 / 15px | 最小の補足。これより小さい文字は使わない |

時刻と数値は等幅数字（`font-variant-numeric: tabular-nums`）で表示し、更新のたびに幅が揺れないようにする。

### 余白・角丸・大きさ

- 余白は4pxを単位に `--space-1`（4px）〜`--space-6`（24px）。
- 角丸は `--radius-s`（8px：ボタン、入力欄）、`--radius-m`（12px：地図のボタン群）、`--radius-l`（16px：パネル、カード）。
- クリック・タップできる対象は `--hit-min`（44px）以上にする。本文中のリンクは除く。

### 素材と影

- 地図の上に浮かぶ層（パネル、カード、地図のボタン、出典表示）は `--color-material` の半透明の下地と背景のぼかし（`--material-filter`）で描く。
- 素材の不透明度はライト90%、ダーク92%。背景地図はダークモードでも明るいままなので、ダークの素材をより不透明にしている。
- 不透明度は、陸・海・雨雲の各色（最も強い雨の色を含む）が素材の真下を全面に覆った場合でも、文字の設計値が4.5:1を保てる値にしている。
- 影は `--shadow-floating` の1種類だけ使う。

## 4. 操作部品

HIGの標準部品に対応させる。v0.7の段階2・3で置き換えるものは予定として示す。

| 役割 | HIGの部品 | 現在 |
| --- | --- | --- |
| 主要な操作（雨雲を更新、再生） | 塗りつぶしボタン（filled） | 実装済み |
| 補助の操作（各レイヤーの更新、閉じる） | グレーのボタン（gray） | 実装済み |
| セクションの開閉 | 開閉の印が右→下に回るディスクロージャー | 実装済み |
| レイヤーのON/OFF | スイッチ | 段階3（現在はチェックボックス） |
| 観測値、再生速度の択一 | セグメンテッドコントロール | 段階3（現在は押し込み式ボタン） |
| 時刻の切替と再生 | 地図下端の再生バー | 段階3（現在はパネル内） |
| 操作パネル | デスクトップはサイドバー、狭い画面はボトムシート | 段階2（現在は固定パネルと縦積み） |

## 5. アクセシビリティ設定

設定に応じて設計値を差し替える。部品側で個別に分岐しない。

| 設定 | 振る舞い |
| --- | --- |
| ダークモード（`prefers-color-scheme: dark`） | 色の設計値をダーク用に差し替える。 |
| 透明度を下げる（`prefers-reduced-transparency: reduce`） | 素材を不透明にし、背景のぼかしをやめる。 |
| コントラストを上げる（`prefers-contrast: more`） | 副の文字と区切り線を濃くし、ボタンに輪郭を付ける。Apple製品と同じく、素材も不透明にする。 |
| 視差効果を減らす（`prefers-reduced-motion: reduce`） | 開閉の回転などの動きをなくす。 |
| 強制カラー（Windowsのハイコントラスト） | 状態の点、警報の色見本、色の尺度はOSの色で上書きさせず、そのまま表示する。 |

## 6. HIGから外している点

- **副の文字色**：HIGの secondaryLabel（ライトで `rgba(60,60,67,.6)`）は白の上で約3.5:1しかなく、WCAG AA（4.5:1）に届かない。時刻や更新状態を副の文字で示すため、濃くしている。半透明の素材越しに地図が透けるため、不透明色で指定する。
- **強調色**：HIGの systemBlue（`#007aff`）は白い文字との組み合わせで約4.0:1になる。塗りつぶしには `#0071e3`、文字には素材とボタンの下地の上でも4.5:1を保てる濃さの青を使う。ダークの文字には、明るい地図が透けた素材の上でも読める明るさの青を使う。
- **行の高さ**：日本語の読みやすさのため、HIGより広げている（上記「文字」）。
- **背景地図の配色**：ダークモードでも背景地図と気象レイヤーは明るい配色のまま。暗い地図にすると雨雲や警報の色の見え方が変わるため、必要性を確認してから扱う。
