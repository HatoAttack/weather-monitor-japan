# ROADMAP.md

## Development policy

各バージョンは1つの主要機能に集中する。

前段階が安定する前に次段階を先行実装しない。

## v0.1 Rain Monitor

Goal:

日本地図上で現在および直近過去の降水情報を確認できる。

Done when:

- 地図が表示される。
- ズームとパンができる。
- 降水レイヤーが表示される。
- レイヤーをON/OFFできる。
- 表示データ時刻が分かる。
- 一定間隔で更新される。
- 複数時刻を切り替えられる。
- 取得失敗時に直前データが残る。

## v0.2 AMeDAS

Goal:

地図上で主要な地上観測値を確認できる。

Status:

`codex/v0.2-amedas` で実装。風の表示は v0.4 後に矢印へ変更。

Candidate data:

- 気温
- 降水量
- 風向
- 風速

Done when:

- 全国の観測地点を地図に表示できる。
- 気温、1時間降水量、風向・風速を確認できる。
- 表示する観測要素を切り替えられる。
- 観測時刻と更新状態を確認できる。
- 取得失敗時に直前の観測値が残る。

## v0.3 Himawari

Goal:

衛星画像から日本周辺の雲の状態を確認できる。

## v0.4 Timeline Player

Goal:

過去データを時間軸で連続再生できる。

Status:

`claude/v0.4-timeline` で実装。対象は雨雲のみ。

Features:

- 再生
- 一時停止
- 時刻選択
- 再生速度

Done when:

- 保持している雨雲の時刻を連続再生できる。
- 再生と一時停止を切り替えられる。
- 再生速度を選べる。
- 画像の読み込みが終わってから次の時刻へ進む。
- 最新時刻まで進んだあと停止する。「繰り返し」を選ぶと先頭へ戻る。
- 時刻を手動で選ぶと再生が止まる。

Out of scope:

- 衛星画像とアメダスの連続再生。必要性を確認してからv0.5以降で扱う。

## v0.5 Precipitation Forecast

Goal:

現在から未来の降水予測まで連続して確認できる。

Status:

`claude/v0.5-forecast` で実装。対象は降水ナウキャストの1時間先まで。

Done when:

- 実況の後ろに予測時刻が並び、1本の時間軸で切り替えられる。
- 表示中の時刻が実況か予測かを区別できる。
- 連続再生が実況から予測まで通しで進む。
- 予測の基準時刻を確認できる。
- 予測の取得に失敗しても実況の表示と操作を維持する。
- 実況が更新されたら予測も差し替え、古い予測を残さない。

Out of scope:

- 降水短時間予報（6時間先）。必要性を確認してからv0.6以降で扱う。
- 予測の確度表示、アメダスと衛星画像の予測。

## v0.6 Alerts

Goal:

気象警報、注意報を地図上で把握できる。

Status:

`claude/v0.6-warnings` で実装。2026年5月からの新しい防災気象情報（警戒レベル付きの名称、危険警報）に対応。

Done when:

- 発表中の警報・注意報を、最も重いものの色で地図に塗れる。
- 全国表示は一次細分区域、拡大時は市町村で表示する。
- 区域・市町村を選ぶと、発表中の種別と発表時刻を確認できる。
- 更新状態と最終確認時刻を確認できる。
- 取得に失敗しても直前の発表状況を維持する。
- 名称の分からない種別コードを推測で表示しない。

## v0.7 UI Refresh

Goal:

Apple Human Interface Guidelines（HIG）に沿って画面を見直し、地図を主役にしたまま、常時表示と狭い画面の両方で使いやすくする。適用ルールは `docs/DESIGN.md` にまとめる。

新しいレイヤーを増やす前に、表示と操作の土台を整える。気象データの取得・保持・更新の振る舞いは変えない。

Status:

段階1（土台）を `claude/v0.7-ui-foundation`、段階2（配置）を `claude/v0.7-ui-layout` で実装。検証結果は `docs/VALIDATION_v0.7.md`。

Steps（1段階＝1PR）:

1. 土台：色・文字・余白・角丸・半透明素材を設計値として定義し、既存の画面へ適用する。配置は変えない。
2. 配置：ヘッダーをやめて地図を全面に表示する。デスクトップは地図に浮かぶサイドバー、狭い画面はボトムシートにする。
3. 操作部品と時間軸：セグメンテッドコントロール、スイッチ、アイコンに置き換える。雨雲の時刻切替と再生を地図下端の再生バーへ移す。

Done when（2. 配置）:

- ヘッダーがなくなり、地図がウィンドウ全面に表示される。
- デスクトップでは操作パネルが地図に浮かぶサイドバーになる。
- 狭い画面では操作パネルがボトムシートになり、閉じた状態から開閉できる。
- ボトムシートを閉じている間も地図の出典表示と拡大縮小が使える。
- 気象データの取得・保持・更新の振る舞いは変わらない。

Done when（1. 土台）:

- 色、文字、余白、角丸、影、半透明素材が設計値として一か所で定義され、画面の各部品がそれを使う。
- 外観がOSのライト/ダーク設定に追従する。
- 文字の大きさがHIGのテキストスタイルのいずれかにそろう。
- ボタンなど主要な操作対象が44×44px以上になる。
- 文字と背景のコントラストが、ライト/ダークの両方でWCAG AA（本文4.5:1）を満たす。
- 「透明度を下げる」「コントラストを上げる」「視差効果を減らす」の設定に追従する。

Out of scope:

- 背景地図と気象レイヤーのダークモード用配色。地図は明るい配色のまま残し、必要性を確認してから扱う。
