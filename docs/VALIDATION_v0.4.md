# v0.4 時間軸の連続再生

## 実装範囲

- 保持している雨雲の時刻を古い順に連続再生し、一時停止できる。
- 再生速度を低速・標準・高速から選べる。速度と待ち時間は `src/app/config.ts` に集約する。
- 各コマは降水画像の読み込み完了を待ってから次へ進む。読み込めない時刻は最大20秒で次へ送り、再生が止まらないようにする。
- 最新時刻では少し待ってから先頭へ戻る。
- 時刻を手動で選ぶと再生を停止し、その時刻を表示したままにする。
- 降水レイヤーが非表示のとき、または保持している時刻が1つのときは再生できない。
- バックグラウンドのタブでは再生を進めず、表示に戻ったときに再開する。
- 対象は雨雲のみ。アメダスと衛星画像の連続再生は扱わない。

## 実装

- 再生状態は `src/hooks/useTimelinePlayer.ts` が持ち、`Timeline` は表示と操作のみを担当する。
- 時刻の選択は既存の `useRainMonitor` の `select` を経由し、時系列の保持と選択の責務は変更しない。

## 検証

- lint、typecheck、単体テスト49件（新規6件）、production build に成功。
- ブラウザ統合テスト4件に成功（固定データ、既存Chrome使用）。新規の再生テストで、連続再生、先頭への復帰、一時停止後に時刻が進まないこと、レイヤー非表示時の再生不可、手動選択による停止を確認。
- 新規依存パッケージなし。

## 検証時の注意

`npm run test:e2e` の開発サーバーはポート5173を使う。別の作業ディレクトリで同じポートの開発サーバーが動いていると、Playwright の `reuseExistingServer` がそちらへ接続し、変更前の画面を検証してしまう。今回の検証中に実際に発生したため、実行前にポート5173の使用状況を確認する。
