# v0.2 アメダス実装・検証報告

実施日：2026-09-09（日本時間）

対象：ロードマップ v0.2 AMeDAS

作業ブランチ：`codex/v0.2-amedas`

## 変更内容

- 気象庁の最新観測時刻、全国の観測地点情報、観測値を取得するアダプターを追加。
- 外部形式を画面へ直接渡さず、アプリ内部の地点・観測モデルへ変換。
- 全国のアメダス地点を MapLibre の独立レイヤーとして追加。
- 気温、1時間降水量、風速の色分け切替を追加。
- 地点選択時に地点名、標高、気温、1時間降水量、16方位の風向、風速を表示。
- 10分間隔の自動更新、古いデータの警告、手動更新を追加。
- 取得失敗時は最後に正常取得した地点と観測値を維持。
- 既存の雨雲表示、時間軸、表示保持を維持。

## 確認結果

| 項目 | 結果 |
| --- | --- |
| 最新観測時刻 | 気象庁の `latest_time.txt` を解釈し、その時刻の観測ファイルを選択できる |
| 地点結合 | 5桁の地点IDで地点情報と観測値を結合できる |
| 座標 | 度・分形式を地図用の十進度へ変換できる |
| 品質・欠測 | 品質コード0の数値のみ採用し、欠測を区別できる |
| 表示切替 | 気温、1時間降水量、風速で色と大きさの尺度を変更できる |
| 地点詳細 | 気温、降水量、風向、風速を1つの地点カードで確認できる |
| 更新失敗 | reducerの障害試験で直前スナップショットと最終成功時刻を保持 |
| 自動更新 | 10分間隔、非表示タブでの抑制、表示復帰時の再確認を仮想時計で検証 |

- アメダスは最新時刻だけを表示し、過去時刻の切替は未実装。

- 気象庁ホームページ用の配信URLと形式に依存するため、外部仕様変更時はアダプターの修正が必要。
