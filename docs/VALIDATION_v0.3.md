# v0.3 ひまわり衛星画像

## 実装範囲

- 気象庁のフルディスクB13赤外画像から最新時刻を取得する。
- MapLibreの独立したラスターレイヤーとして表示し、雨雲・アメダスと別にON/OFFできる。
- 観測時刻、更新状態、最終確認成功時刻を表示する。
- 10分ごとに更新を確認し、取得や画像読み込みの失敗時は直前の表示を維持する。
- 初期状態は非表示とし、時系列再生と画像種別切替はv0.4以降とする。

## 検証

- lint、typecheck、単体テスト43件、production buildに成功。
- 最新時刻一覧とB13赤外タイルを実データで取得し、JPEGタイルのHTTP 200を確認。
- 新規依存パッケージなし。
