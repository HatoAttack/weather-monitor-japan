# Weather Monitor Japan

日本の現在の気象状況を、地図を中心にリアルタイムに近い形で眺め続けるためのWebアプリです。

一般的な天気予報サイトのように「今日の天気」を読むことよりも、「いま日本の空で何が起きているか」を地図上で把握できることを重視します。

## Current target

現在はv0.1を対象とします。

v0.1では以下を実現します。

- 日本地図の表示
- 地図のズーム、パン
- 降水情報レイヤーの表示
- 降水レイヤーのON/OFF
- 気象データ時刻の表示
- 一定間隔での最新データ確認
- 過去データの時刻切り替え

## Product concept

画面中央の地図を主役とし、雨雲、衛星画像、アメダス、警報などを必要に応じてレイヤーとして重ねます。

将来的には、サブモニターや常時表示用の気象ダッシュボードとして使えることを目指します。
