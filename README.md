# Weather Monitor Japan

日本の現在と直近過去の雨雲を、地図を中心に確認する Web アプリです。v0.1（Issue #1）の実装です。

## 起動

Node.js 24 LTS と npm を推奨します（Node.js 22.12 以上）。WebGL を利用できるモダンブラウザと、インターネット接続が必要です。API キーや環境変数、バックエンドは不要です。

```sh
git clone https://github.com/HatoAttack/weather-monitor-japan.git
cd weather-monitor-japan
git switch codex/v0.1-rain-monitor
npm ci
npm run dev
```

端末に表示された URL（通常は http://127.0.0.1:5173/ ）を開きます。

```sh
npm run build
npm run preview
```

本番用ファイルは `dist/` に出力されます。HTTPS の静的ホスティングに配置できます。ローカルファイルを直接開く `file://` では起動できません。公開先へのデプロイはこのタスクには含めていません。

## 操作

- 日本地図：ドラッグで移動、ホイールまたは ＋ / − ボタンで拡大縮小。
- キーボード：地図にフォーカスして矢印キーで移動、＋ / − キーで拡大縮小。
- 「降水レイヤーを表示」で雨雲の表示を切替。
- 時刻の選択欄、前後ボタン、スライダーで直近の観測時刻を切替。
- 「最新へ」で最新時刻に戻る。最新を表示中は新しい観測に追従する。過去時刻を選択中はその時刻を維持する。
- 「自動更新」は5分間隔。チェックを外すと停止し、「更新を確認」で手動取得できる。バックグラウンドのタブでは定期取得を控える。
- 時刻はすべて日本時間（JST）。大きく表示する時刻は、画像の読み込みに成功して地図に反映された時刻。選択した時刻を取得中・取得失敗の場合は、選択中の時刻を別に表示する。

## データと更新

降水実況は [気象庁「雨雲の動き」](https://www.jma.go.jp/bosai/nowc/)、背景は [国土地理院「地理院タイル（淡色地図）」](https://maps.gsi.go.jp/development/ichiran.html) を利用します。地図と画面内に出典を表示しています。降水画像は透過度を変更して重ねて表示します。

- 気象庁の `targetTimes_N1.json` から `hrpns` の時刻を取得する。基準時刻と対象時刻が同じ実況だけを採用し、未来の時刻・予測は取り込まない。
- 通常は最新13時刻（5分刻みなら約1時間）。重複を除き、観測時刻順に並べる。閲覧中の過去時刻が範囲外になった場合は1時刻だけ追加保持する。
- 最新の取得データが15分以上古い場合は警告する。
- 正常、更新中、新規データなし、一時的な取得失敗、データ形式エラーを区別する。最終確認成功時刻も表示する。
- 時刻一覧の取得失敗では取得済みデータを保持する。新しい降水タイルは別のレイヤーで読み込み、表示範囲の読み込みが完了してから切り替える。画像取得失敗・タイムアウト時は直前のレイヤーと表示時刻を維持する。「画像を再試行」で再取得できる。
- タイムアウトは時刻一覧15秒、降水レイヤー20秒。設定は `src/app/config.ts` に集約する。

2026-09-08 の検証では、気象庁・国土地理院のデータをブラウザから直接取得できました。気象庁ホームページ用の配信 URL を利用しており、一般向けの安定 API として保証されているものではありません。URL・レスポンス形式・CORS の変更やデータ公開期間の終了で取得できなくなる場合があります。その場合はアダプターを確認してください。

出典と利用条件：
- [気象庁ホームページについて](https://www.jma.go.jp/jma/kishou/info/coment.html)
- [地理院タイル仕様](https://maps.gsi.go.jp/development/siyou.html)

## 構成

React + TypeScript + Vite + MapLibre GL JS。状態管理は React 標準機能のみです。

```text
src/app/                    画面構成、スタイル、設定
src/components/             地図、降水レイヤー、時刻切替、更新状態
src/hooks/                  自動更新と画面状態の接続
src/weather/domain/         アプリ内部の型とエラー
src/weather/adapters/jma/    気象庁 URL・形式の検証と変換
src/weather/services/        時系列保持・選択・更新状態
src/utils/                  日本時間の表示
e2e/                        ブラウザ統合テスト
```

元の設計資料は `AGENTS.md`、`docs/REQUIREMENTS.md`、`docs/ARCHITECTURE.md`、`docs/ROADMAP.md`、`CODEX_TASK_v0.1.md` を参照してください。

## 検証

```sh
npm run lint
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

通常のブラウザテストは固定の時刻一覧と画像で実行し、外部サービスへアクセスしません。実データの検証は明示的に有効にします。

```sh
# macOS / Linux
LIVE_WEATHER=1 npm run test:e2e

# PowerShell
$env:LIVE_WEATHER = '1'
npm run test:e2e
```

既存 Chrome を使用する場合は `PLAYWRIGHT_CHROME_PATH` に実行ファイルの絶対パスを設定できます。ブラウザテストは画面操作、通信障害と復旧、画像・時刻の保持、狭い画面を確認します。実行結果は `docs/VALIDATION_v0.1.md` を参照してください。

## 既知の制約と次の最小タスク

- データと画像の保持は開いているページのメモリ内のみ。再読み込みやブラウザ終了をまたぐ保存は行わない。
- 通信が切れた状態で、未取得の地域へ移動したり未取得の倍率へ拡大したりすると、その範囲の画像は表示できない。配信終了した過去時刻についても、未取得のタイルは復元できない。
- タイルの欠損・404も取得失敗として扱い、雨がないこととは同一視しない。
- 初回の JavaScript は地図ライブラリを含み約1.2 MB（gzip 約330 KB）。ビルド時にサイズ警告が出るが、ビルドは成功する。
- 次の最小タスクは、実際に使うPCで数時間の連続表示を行い、更新遅延・接続切断からの復帰・メモリ使用量を確認すること。

v0.2以降のアメダス、衛星画像、アニメーション、降水予測、警報などは実装していません。
